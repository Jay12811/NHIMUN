# Shrawan MUN Website (Electric Maximalism)

Static multi-page site ready for GitHub + Vercel.

## Pages
- Home: `index.html`
- Allocation: `allocation.html`
- Delegate Benefits: `benefits.html`
- Committees & Agendas: `committees.html`
- Delegate Material: `materials.html` (accordion sections)

## Add your documents
Place PDFs/DOCX in `assets/` and update the links inside the HTML pages.

## Run locally
Just open `index.html` in your browser, or use a simple local server.

## Deploy on Vercel (static)
Import the GitHub repo in Vercel and deploy. No build command needed.
